# Privacy Policy — AI App Doctor

_Last updated: 12 November 2026_

This plugin is a set of instructions (skills) that runs inside Claude. It has no servers of its own.

- **No data collection.** The plugin author does not receive, store or process your code, logs, data or reports.
- **What Claude reads.** Within your Claude session, Claude reads the project files, logs and repository you give it access to. Code can contain personal data or credentials; the plugin instructs Claude never to print full secrets and never to commit them. Processing happens under Anthropic's terms and privacy policy.
- **No storage, no third parties.** Nothing is stored or sent anywhere by the plugin.
- **No tracking, cookies or analytics** are added by the plugin.
